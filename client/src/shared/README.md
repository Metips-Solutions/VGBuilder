# shared (client)

## Qué va aquí

Elementos transversales a toda la aplicación frontend:
- Clientes HTTP y wrappers de fetch hacia la API del backend.
- Definiciones de tipos TypeScript globales del frontend.
- Utilidades comunes de formato, fechas o constantes globales.

## Qué NO va aquí

- Lógica de dominio específica de inventario o afinidad.
- Componentes visuales acoplados a una funcionalidad particular.
